DATA VISUALIZATION LAB – USING THE FIVE UPLOADED CSV FILES

Files:
- Experiment_1.ipynb through Experiment_8.ipynb: eight separate notebooks
- datasets/: all five supplied CSV files
- requirements.txt: required Python packages

Run:
1. Open this folder in VS Code.
2. Install packages: python3 -m pip install -r requirements.txt
3. Open an Experiment_N.ipynb file and select your Python kernel.
4. Run cells from top to bottom.

The notebook expects the datasets folder to stay beside the experiment notebooks.

Important dataset-specific adjustments:
- The supplied files are a retail star-schema dataset, not Superstore or Olympics.
- Experiment 6 uses category sales share instead of Olympic medal share because there are no medal records.
- Experiment 5 maps the eight Indian cities in the supplied geography table.
- Experiment 8 demonstrates forecasting from only three months of data, so forecasts are illustrative only.
